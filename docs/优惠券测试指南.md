# 优惠券功能测试指南

## 快速测试步骤

### 准备工作
1. 确保后端服务正在运行
2. 确保前端服务正在运行
3. 打开浏览器开发者工具的Console面板（用于查看调试信息）

### 测试场景1：满减券测试

#### 步骤：
1. **登录测试账号**
   - 用户名：`user1001` 或其他ID为1001的测试账号
   - 密码：根据系统设置

2. **浏览高价课程**
   - 选择价格≥100元的课程（如199元的课程）
   - 进入课程详情页

3. **选择满减券**
   - 在优惠券下拉框中选择"满100减30"
   - 观察"预计支付"金额是否变为169元（199-30=169）

4. **验证Console输出**
   ```
   选择优惠券: 6101
   选中的优惠券详情: {name: "满100减30", type: 1, discountAmount: 30, thresholdAmount: 100, ...}
   价格计算: {原价: 199, 优惠券: "满100减30", 门槛: 100, 折扣: 30, 最终价格: 169}
   ```

### 测试场景2：折扣券测试

#### 步骤：
1. **在同一课程页面**
2. **选择折扣券**
   - 选择"95折通用"优惠券
   - 观察"预计支付"金额是否变为189.05元（199×0.95=189.05）

3. **验证Console输出**
   ```
   选择优惠券: 6102
   选中的优惠券详情: {name: "95折通用", type: 2, discountRate: 0.95, thresholdAmount: 0, ...}
   价格计算: {原价: 199, 优惠券: "95折通用", 门槛: 0, 折扣: 9.95, 最终价格: 189.05}
   ```

### 测试场景3：门槛限制测试

#### 步骤：
1. **浏览低价课程**
   - 选择价格<100元的课程（如59元的课程）
   - 进入课程详情页

2. **检查优惠券列表**
   - 确认"满100减30"优惠券不出现在下拉列表中
   - 确认"95折通用"优惠券仍然可选

3. **验证Console输出**
   ```
   加载到的优惠券: [{name: "95折通用", ...}]  // 注意：满减券被过滤掉了
   ```

### 测试场景4：完整购买流程

#### 步骤：
1. **选择优惠券并购买**
   - 在199元课程页面选择"满100减30"
   - 确认预计支付169元
   - 点击"立即购买"

2. **验证订单创建**
   - 确认订单页面显示正确的优惠金额
   - 原价：199元
   - 优惠：30元
   - 实付：169元

3. **完成支付测试**
   - 在订单页面点击"立即支付"
   - 选择支付方式并确认
   - 验证订单状态变为"已支付"

## 常见问题排查

### 1. 优惠券不显示
**可能原因：**
- 用户未登录
- 用户没有可用优惠券
- 课程价格不满足优惠券使用门槛

**排查方法：**
- 检查Console是否有"加载到的优惠券"日志
- 确认用户ID和优惠券数据是否匹配

### 2. 价格计算错误
**可能原因：**
- 前端缓存问题
- 优惠券数据格式问题

**排查方法：**
- 查看Console中的"价格计算"日志
- 硬刷新页面（Ctrl+F5）
- 检查优惠券数据结构

### 3. 选择优惠券无反应
**可能原因：**
- JavaScript错误
- 数据绑定问题

**排查方法：**
- 检查Console是否有错误信息
- 查看"选择优惠券"和"选中的优惠券详情"日志

- `GET /api/order/coupon/available?orderAmount=199` - 获取可用优惠券
- 确认返回的优惠券数据结构正确

### 3. 数据库检查
如果需要直接检查数据库：
```sql
-- 查看用户优惠券
SELECT uc.*, c.name, c.type, c.discount_amount, c.discount_rate, c.threshold_amount
FROM t_user_coupon uc
JOIN t_coupon c ON uc.coupon_id = c.id
WHERE uc.user_id = 1001 AND uc.status = 0;

-- 查看优惠券详情
SELECT * FROM t_coupon WHERE id IN (6001, 6002);
```

## 注意事项

1. **测试环境**：确保使用的是测试数据库，避免影响生产数据
2. **用户权限**：确保测试用户有相应的优惠券
3. **时间有效性**：确保优惠券在有效期内
4. **浏览器兼容性**：建议使用Chrome或Firefox进行测试
5. **清除缓存**：测试前建议清除浏览器缓存

如果测试过程中遇到问题，请参考Console日志和网络请求进行排查，或联系开发团队获取支持。
