# 支付功能改进说明

## 问题描述
学生购买课程后，订单显示为"待支付"状态，但没有明显的支付选项或支付流程不够清晰。

## 原问题分析

1. **原有功能实际上是正常的**：
   - 订单列表页面已经有"立即支付"按钮
   - 点击后会弹出确认框
   - 确认后自动完成支付（模拟支付）

2. **用户体验问题**：
   - 支付流程过于简单，缺少支付方式选择
   - 没有明确的支付界面，用户可能不知道如何操作
   - 支付方式固定为支付宝（payType: 1），没有选择余地

## 改进内容

### 1. 新增支付方式选择对话框

在 `frontend/src/views/user/orders.vue` 中添加了新的支付对话框：

**功能特点**：
- 显示订单金额和课程信息
- 提供支付宝和微信两种支付方式选择
- 美观的卡片式布局
- 明确的选中状态提示
- 模拟支付环境提示

**支付方式**：
- 支付宝支付（payType: 1）
- 微信支付（payType: 2）

### 2. 改进支付流程

**原流程**：
```
点击"立即支付" → 弹出确认框 → 点击"确定支付" → 完成支付
```

**新流程**：
```
点击"立即支付" → 打开支付方式选择对话框 → 选择支付方式 → 点击"确认支付" → 完成支付
```

### 3. UI/UX 改进

- **支付金额突出显示**：使用渐变色背景和大字体显示金额
- **支付方式图标**：添加支付宝和微信的SVG图标
- **选中状态**：高亮显示当前选中的支付方式
- **模拟支付提示**：明确告知用户这是模拟支付环境

## 技术实现

```typescript

const orderToPay = ref<OrderInfo | null>(null)  // 待支付订单
const selectedPayType = ref(1)         // 选中的支付方式
const paying = ref(false)              // 支付中状态
```

### 修改的函数
```typescript
// 打开支付对话框
async function pay(o: OrderInfo) {
  orderToPay.value = o
  selectedPayType.value = 1
  paymentVisible.value = true

// 确认支付
async function confirmPay() {
```

## 使用说明

### 学生端操作流程

1. **浏览课程并购买**
   - 在课程详情页点击"立即购买"
   - 系统创建订单并跳转到"我的订单"页面

2. **查看待支付订单**
   - 在"我的订单"页面，点击"待支付"标签
   - 找到刚创建的订单

3. **完成支付**
   - 点击订单中的"立即支付"按钮
   - 在弹出的支付对话框中选择支付方式（支付宝或微信）
   - 点击"确认支付"按钮
   - 看到"支付成功"提示，订单状态变为"已支付"

4. **开始学习**
   - 支付成功后，可以点击"去学习"按钮开始学习课程

### 其他入口

- **订单详情弹窗**：也可以在订单详情中点击"立即支付"
- **订单超时**：订单创建后30分钟内未支付会自动取消

## 注意事项

1. **模拟支付环境**
   - 当前实现的是模拟支付，不涉及真实的支付接口对接
   - 点击"确认支付"后直接完成支付，无需真实付款

2. **订单过期时间**
   - 订单创建后30分钟内有效
   - 超时后订单自动取消，需要重新购买

3. **已购买课程**
   - 已购买的课程不能重复购买
   - 系统会在购买时检查是否已购买
